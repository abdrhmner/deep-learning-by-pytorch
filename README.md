# 🍔 FoodVision - Food Image Classification with PyTorch

FoodVision is a Deep Learning project built using **PyTorch** that classifies food images into different categories using **Convolutional Neural Networks (CNNs)** and **Transfer Learning**.

The model is trained and deployed as an interactive web app using **HuggingFace Spaces**.

🚀 Live Demo:  
https://huggingface.co/spaces/abdrhmnr/food_vision_big/

---

## 📌 Project Features

- ✅ Built with PyTorch
- ✅ Uses Transfer Learning with EfficientNet
- ✅ End-to-end training & evaluation pipeline
- ✅ Image preprocessing & augmentation
- ✅ Deployed as a web app on HuggingFace Spaces
- ✅ Simple and clean UI for testing the model
